**النسخة:** 1.0 — تاريخ: 2026-11-04

## 2) أهم تصحيح مفاهيمي قبل أي عمل

1. **PPSSPP ليس libretro frontend.** لا يوجد في كوده أي طبقة تستقبل `retro_run()` أو `retro_load_game()`. ما تطلبه يعني بناء الطبقة التالية من الصفر داخل مشروع PPSSPP:
   إدارة حياة الـ Core + سياق فيديو OpenGL ES + مسار صوت + خرائط إدخال + حفظ حالة + كشف ألعاب + ربط إعدادات + عرض أخطاء بأسلوب PPSSPP.
2. **"35 Core" غير دقيق:** الأنظمة الـ35 تُغطّى بـ **~22 ملف Core فقط** (Genesis Plus GX وحده يغطي 5 أنظمة، FBNeo يغطي Arcade + Neo Geo CD، إلخ). الجيد أن هذا يقلّل العمل؛ السيئ أن أي Core يسقط يُسقط معه 3–5 أنظمة دفعة واحدة — لذلك **العزل بالعملية (§7) إلزامي وليس ترفاً**.
3. **ملفات BIOS محمية بحقوق نشر.** لا يمكن شحنها داخل APK (البند 6 يشترط "تقليص ملفات BIOS" — وهذا غير ممكن قانونياً: لا يجوز شحنها أساساً). الحل الوحيد: استيراد من ملفات المستخدم (§9).

## 7) البنية المعمارية المقترحة

```
ppsspp-fork/
├─ Core/ , GPU/ , HLE/ , UI/        ← لا تُلمس (PSP) — قاعدة صارمة
├─ extcores/                        ← كل الكود الجديد هنا فقط
│  ├─ host/          تحميل الـ Core (dlopen + libretro API) وإدارته
│  ├─ video/         سياق GLES + إخراج إلى نسيج يعرضه PPSSPP نفسه
│  ├─ audio/         AAudio/OpenSL ← نفس مسار صوت PPSSPP
│  ├─ input/         تحويل أزرار PPSSPP (شاشة + يد) إلى retro joypad
│  ├─ detect/        جدول الامتدادات + بصمة رأس الملف (magic bytes)
│  ├─ settings/      ترجمة إعدادات PPSSPP ↔ core options لكل Core
│  ├─ ipc/           قناة الأوامر مع عملية الـ Core
│  └─ ui/            تسجيل الأنظمة في قائمة الألعاب + أيقونات + رسائل بأسلوب PPSSPP
├─ cores/<abi>/<core>.so           ← مبنية من مصادرها الخاصة (لم تُعدّل)
└─ android/                        ← Gradle: خدمة منفصلة + تقليل حجم
```

**العزل (البند 4.ج) — الطريقة الوحيدة التي تعمل على أندرويد:**
كل Core خارجي يعمل في **عملية أندرويد منفصلة** (`android:process=":extcore"`) توصَل بالواجهة عبر ذاكرة مشتركة (فيديو/صوت) + قناة أوامر. إذا مات الـ Core أو حصل SIGSEGV:
1. تموت العملية الفرعية فقط، وواجهة PPSSPP تبقى حيّة، وCore الـ PSP غير متأثر إطلاقاً (هو في العملية الرئيسية).
2. تُعرض رسالة خطأ **بتصميم PPSSPP الأصلي** ("تعذّر تشغيل هذا النظام — Core لم يستجب")، ثم إعادة تشغيل الخدمة تلقائياً.
3. هذا بالضبط ما كان ينقص في محاولتك السابقة: بلا عزل بالعملية، أي Core منهار = التطبيق كله منهار، ولا يوجد "إصلاح كود" يعالج ذلك.

## 9) سياسة BIOS وROM — لا مفر منها قانونياً

- **لن يُشحن أي BIOS أو ROM محمي بحقوق نشر** داخل الـ APK، ولا "نسخة مقلّصة" منها. من يطلب منك ذلك يورّطك لا يساعدك.
- بديل الاختبار: **105 لعبة تجريبية = محتوى حرّ الترخيص** (240p Test Suite بترخيص حرّ، وألعاب homebrew مفتوحة لـ NES/GB/GBA/Genesis/N64/PSX/Dreamcast، وحزم libretro الاختبارية). هذا يحقق "3 ألعاب لكل نظام" بشكل قانوني سليم، وأستطيع توثيق نتيجة كلٍّ منها.
- أي نظام يعتمد على BIOS (Sega CD، Saturn، 3DO، Amiga، MSX، PC-98، PSX) سيُسلَّم معه: نظام استيراد ملفات + رسالة إرشادية بأسلوب PPSSPP، وتوثيق أسماء الملفات المطلوبة ومواضعها.

## 11) مسار البناء والتسليم المقترح (لأنني لا أستطيع إنتاج APK من هنا)

1. أُسلّمك حزمة: المصدر الكامل + `extcores/` + `CMakeLists` + Gradle + سكربت `build.sh` لبناء الـ Cores لكل معمارية + ملف `Dockerfile` + سير عمل **GitHub Actions** ينتج APK موقّعاً عند كل وسم إصدار.
2. تبني بنقرة واحدة على GitHub (مجاني، آلات 4–8 أنوية) أو على جهازك. الـ Workflow يُنتج `arm64-v8a` و `armeabi-v7a` كملفَّين منفصلين (وهذا أيضاً يقلّص الحجم ~45%).
3. الـ Keystore: أُولّده وأسلّمه كملف + تعليمات، **لكن** نصيحتي الأمنية: لا تُرسل كلمات المرور في محادثة. الأفضل أن تُولّده أنت محلياً بالأمر الموثّق في README، وتُودع نسخة احتياطية في مدير كلمات مرور — فقدان Keystore يعني استحالة تحديث التطبيق على أي جهاز مثبّت عليه.
4. رفع الملفات إلى Google Drive: متاح من خلال تكامل Drive المتصل في هذه المحادثة — سأرفع **الوثائق والمصدر والـ APK حين يوجد** بنفس الأسماء العربية المطلوبة.

## 12) التسمية والعلامة التجارية

PPSSPP® اسم فريق مستقل وله أيقونة مسجّلة بصرياً — الابتعاد عنه صحيح. اقتراحات (كلها لا تستخدم كلمة PSP):
- **Sphynx** — قصير، سهل النطق، أيقونة رأس قط/أبو الهول
- **Nexus Play** / **NexPlay**
- **OmniCell**
- **Kemet** (كلمة مصرية قديمة، تعبير جميل عن "الأرض السوداء الخصبة")

أيقونة مختلفة تماماً: شكل هندسي أحادي اللون (مثلاً حلقة مفتوحة + لاعب مجرّد)، لا تحتوي أي أزرار أو حروف تشبه شعار PPSSPP.
