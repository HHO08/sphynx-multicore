# دليل البناء والتوقيع وإضافة الأنظمة

## 1. بناء APK

### على GitHub Actions (الطريقة المُجهّزة)

المستودع `HHO08/sphynx-multicore`، الفرع `sphynx-multicore-1.18.1`.
كل دفع إلى الفرع يشغّل تلقائياً:

| الـ Workflow | ما يفعله | المدة |
|---|---|---|
| `Sphynx host tests (fast, no Android SDK)` | يبني `extcores/` بأداة النظام ويتحقق من 79 شرطاً | ~30 ثانية |
| `Sphynx APK (signed release, per-ABI)` | يبني APK لكل معمارية، يوقّعه، يفحص الحجم، ينشر البصمات | ~9 دقائق |

الناتج: قطعتان (artifact) باسم `sphynx-arm64-v8a-release` و
`sphynx-armeabi-v7a-release`، كل واحدة تحوي APK + `SHA256SUMS.txt`.
أي ملف يتجاوز 100 م.ب **يُفشل البناء** (بوابة صريحة في الـ workflow).

### على جهازك

```bash
git clone --recursive -b sphynx-multicore-1.18.1 https://github.com/HHO08/sphynx-multicore.git
cd sphynx-multicore

# متطلبات: JDK 17، Android SDK (compileSdk 35)، NDK 21.4.7075529 (يُثبّتها Gradle تلقائياً)

./gradlew assembleNormalRelease -PsphynxAbi=arm64-v8a  -PANDROID_VERSION_NAME=1.18.1-sphynx.0
./gradlew assembleNormalRelease -PsphynxAbi=armeabi-v7a -PANDROID_VERSION_NAME=1.18.1-sphynx.0
```

المخرجات في `android/build/outputs/apk/normal/release/`.

**الحجم**: قدرة الجهاز الواحد على بناء معماريتين معاً قد تفشل بـ OOM؛ بناء
معمارية واحدة في كل مرة هو الافتراضي هنا عمداً.

### بناء نسخة PPSSPP خالصة (بلا أي Core خارجي)

```bash
./gradlew assembleNormalRelease -PsphynxAbi=arm64-v8a -DSPHYNX_EXTCORE=OFF
```
أو على CMake: `-DSPHYNX_EXTCORE=OFF` — يُخرِج شجرة مطابقة للأصل تماماً.

## 2. التوقيع

المفتاح: `keystore/sphynx-release.keystore` (RSA 4096، صالح 30 سنة، alias `sphynx`).
المعلومات الكاملة في `keystore/keystore-info.txt` داخل مساحة العمل.

### كيف يستعمله الـ CI

أربعة أسرار في المستودع (Settings → Secrets and variables → Actions):

| السر | القيمة |
|---|---|
| `SPHYNX_KEYSTORE_BASE64` | `base64 -w0 sphynx-release.keystore` |
| `SPHYNX_KEYSTORE_PASSWORD` | من `keystore-info.txt` |
| `SPHYNX_KEY_ALIAS` | `sphynx` |
| `SPHYNX_KEY_PASSWORD` | من `keystore-info.txt` |

الـ workflow يفكّ الملف إلى `$RUNNER_TEMP` ويكتب كلمات المرور في
`~/.gradle/gradle.properties` — **لا تمرّ عبر سطر أوامر**، فلا تظهر في أي سجل.

### كيف تستعمله محلياً

```bash
cat >> ~/.gradle/gradle.properties <<'EOF'
RELEASE_STORE_FILE=/absolute/path/sphynx-release.keystore
RELEASE_STORE_PASSWORD=...
RELEASE_KEY_ALIAS=sphynx
RELEASE_KEY_PASSWORD=...
EOF
```

### قواعد الترقية
- **لا تفقد** هذا الملف: بدونه لا يمكن تحديث التطبيق على أي جهاز مثبّت عليه.
- خزّنه في مدير كلمات مرور + نسخة دون اتصال.
- كل تحديث لاحق يجب أن يستخدم **نفس** `applicationId` ونفس المفتاح.
- `versionCode` يأتي من وسم git تلقائياً (`1.18.1` → `118010001`).
  عند إصدار تحديث: أنشئ وسمًا مثل `v1.18.2` فيرتفع الرقم تلقائياً.

## 3. البنية: من أين يبدأ كل شيء

```
extcores/
├─ include/sphynx_extcore.h     ← الواجهة العامة الوحيدة (كل العقود هنا)
├─ include/libretro.h           ← نسخة libretro API الرسمية (GPL-compatible)
├─ src/system_db.cpp            ← قائمة الـ35 نظاماً + الكشف + SelfCheck
├─ src/core_loader.cpp          ← dlopen + 25 نقطة دخول إلزامية
├─ src/env_callback.cpp         ← retro_environment (خيارات الـ Core، المجلدات…)
├─ src/session.cpp              ← دورة حياة الـ Core، الصوت، الإدخال، الحفظ، watchdog
├─ jni/sphynx_extcore_jni.cpp   ← جسر أندرويد
├─ tests/stub_core.c            ← Core وهمي مطابق للمواصفة (للاختبار فقط)
└─ tests/host_smoke.cpp         ← 79 تحقّقاً — يعمل بلا Android SDK
```

`android/src/org/sphynx/emulator/SphynxExtCore.java` = الطبقة الجاوية، **خاملة**:
إن غاب الـ `.so` يعود التطبيق لسلوك PPSSPP الافتراضي دون انهيار.

### إضافة نظام جديد (أو Core جديد)

1. أضف سطراً في `kSystems` في `src/system_db.cpp`، وأضف معرّفاً في
   `enum class SystemId` في `sphynx_extcore.h`.
2. أضف سطراً في `kCores` للـ Core إن لم يكن موجوداً (بالترخيص والتحقق منه).
3. أضف حالات الكشف في `Detect()` إن كان للنظام بصمة magic.
4. أضف الاختبارات في `tests/host_smoke.cpp` (وجود النظام + كشفه).
5. شغّل `./out/sphynx_host_smoke` — يجب أن يبقى 0 أخطاء.
6. أضف المستودع كمكوّن ثانوي (submodule) وابْنِه:
   ```bash
   git submodule add https://github.com/libretro/mgba.git extcores/cores/mgba
   # البناء: يُخرج mgba_libretro.so باسم libsphynx_core_mgba.so
   ```
7. لا تعدّل كود الـ Core نفسه إلا للتصريف على ARM Android؛ وسّم أي تعديل بـ
   `SPHYNX:` ووثّقه في `docs/patches/`.

## 4. قواعد ثابتة في هذا المشروع

1. لا يُلمس `Core/`، `GPU/`، `HLE/`، `UI/`. للتحقق:
   ```bash
   git diff v1.18.1 --stat -- Core GPU HLE UI Common
   ```
2. لا إعلانات، لا تتبّع، لا اتصال شبكي من طبقة الكورات. لا صلاحيات جديدة في
   `AndroidManifest.xml`.
3. لا يُشحن أي BIOS أو ROM. الكورات التي تحتاجها تشرح للمستخدم كيف يستوردها.
4. كل انهيار محتمل في Core خارجي يجب أن ينتهي في عملية منفصلة (`:extcore`)،
   لا في عملية PPSSPP.
5. أي كور بترخيص غير متوافق يُستبعد أو يُترك خلف علامة «غير مدعوم» — لا استثناء.
