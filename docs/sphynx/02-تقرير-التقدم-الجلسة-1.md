### تصحيح مهم لتقديري السابق في تقرير الجدوى
قدّرت في التقرير السابق أن PPSSPP نفسه ≈ 40 م.ب خام، والقياس الفعلي **19.9 م.ب لكل معمارية**، ونسبة ضغط الكود ≈ 36% لا 50%. هذا **يحسّن ميزانية الحجم تحسناً كبيراً**:

- تقدير جديد لكل الأنظمة في APK **واحد لكل معمارية**: `20 م.ب (PSP) + ~30–35 م.ب (الكورات مضغوطة) ≈ 50–58 م.ب` → **تحت السقف بمساحة أمان**.
- أي أن خيارك (ملفَّان منفصلان لكل معمارية) ليس مجرد حلٍّ للضغط، بل يترك هامشاً حقيقياً لإضافة كل الأنظمة الـ35 دون أي تنازل.

هذا تقدير لا وعد: سيتم قياسه الحقيقي كلما أُضيف Core. البوابة في CI ستفشل تلقائياً إن تجاوز أي ملف 100 م.ب.

## 3) ما لم يُنجز بعد في هذه المرحلة (بصراحة)

- **لا يوجد أي Core خارجي بعد.** التطبيق الحالي = PPSSPP v1.18.1 بالكامل، موسوم باسم Sphynx. أي لعبة PSP تعمل فيه كما في الأصل تماماً (لم يُلمس الكود).
- **الأيقونة لم تُغيَّر بعد** — ما زالت أيقونة upstream. مطلوب قرارك في الاسم قبل تصميم هوية بصرية نهائية.
- **م1 (جسر `extcores` + Core واحد)** لم يبدأ: ينتظر ردّك على القرارات الواردة في نهاية هذا التقرير (تُكرَّر في القسم 5).

## 4) تفاصيل تقنية للمراجعة

**التعديلات الثلاثة الوحيدة على الكود الأصلي** (كلها موسومة `SPHYNX:`):

1. `android/res/values/strings.xml` → اسم التطبيق واسم الاختصار.
2. `android/build.gradle` → `applicationId` لمنتج `normal`، و`abiFilters` أصبح قابل التحكم بـ `-PsphynxAbi=` (ARM فقط).
3. ملف جديد `.github/workflows/sphynx-apk.yml` (لم يكن موجوداً).

`Core/`, `GPU/`, `HLE/`, `UI/`, `Common/` — **صفر تغييرات**. تحقّق بأمر واحد:
```bash
git diff v1.18.1 --stat -- Core GPU HLE UI Common
```

**أمان المفتاح:** كلمات مرور الـ keystore لم تُمرَّر على سطر أوامر أبداً (وإلا ظهرت في سجلات CI العامة). تُكتب في `~/.gradle/gradle.properties` على جهاز البناء من GitHub Secrets، والملف نفسه لا يُرفع للمستودع.

**ملاحظة أمنية بخصوص التوكن:** التوكن الذي أرسلته يمنح صلاحيات كاملة على حسابك (repo + workflow + delete_repo). أنا لم أستخدمه إلا في: إنشاء الـ fork، دفع 3 كوميتات، تفعيل Actions، وتعيين 4 أسرار. **أوصي بشدة بحذفه الآن** من GitHub (Settings → Developer settings → Tokens) وإنشاء واحد جديد بصلاحية `repo` فقط إذا احتجت لاحقاً. لن أحتاجه مجدداً بعد انتهاء هذه الجلسة إلا إذا طلبت مني متابعة العمل على نفس المستودع.
