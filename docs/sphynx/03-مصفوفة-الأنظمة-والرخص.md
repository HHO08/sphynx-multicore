# مصفوفة الأنظمة الـ35 — الـ Core، الترخيص، الـ BIOS، والأداء المتوقّع

هذه هي القائمة المرجعية النهائية كما هي **مُرمَّزة فعلياً** في
`extcores/src/system_db.cpp` (اختبار `SelfCheck` يفرض أنها 35 بالضبط).
أي تعديل هنا يجب أن يتبعه تعديل في الملف المذكور، وإلا فشل الاختبار في CI.

**اصطلاحات:** «حجم» = حجم الـ `.so` المقدّر بعد التصريف والضغط، لكل معمارية.
«ضعيف» = جهاز بمعالج A53/A7 وذاكرة 2 غيغا. «متوسط» = A73/A55 حديث.

## الخلاصة الرقمية

| البند | القيمة |
|---|---|
| عدد الأنظمة | **35** (مُتحقَّق بالاختبار) |
| عدد ملفات الـ Core الفعلية | **20** |
| حجم كل الكورات لكل معمارية (تقديري بعد الضغط) | **≈ 33 م.ب** |
| PPSSPP نفسه (مقاس فعلياً) | **19.9 م.ب** |
| **الإجمالي المتوقع لكل APK** | **≈ 53 م.ب** ✔ تحت السقف بهامش 47 م.ب |
| كورات تحتاج تدقيقاً قانونياً قبل الشحن | fbneo، opera، picodrive، np2kai |
| كورات GPLv3 (تفرض ترقية الترخيص الكلي) | melonds، bsnes، gearsystem |
| أنظمة لا تعمل على أجهزة ضعيفة (بصراحة) | N64، NDS، Saturn، Dreamcast، 3DO، PC-FX، PSX (جزئياً) |
